# Deploy-verification toolchain dependencies (Pass12, 2026-11-08).
#
# These are the pip packages needed to RUN the four-dimension deploy gate that lives in
# this directory:
#   - verify_policy_bundle.py  -> needs onnx (+ numpy for the numeric normaliser checks)
#   - rehearse_hd1910.py       -> needs onnx (reads runmeta/heading_meta to infer plant)
#   - audit_robotd_toml.py     -> stdlib only (tomllib, Python >= 3.11)
#   - pre_deploy_check.py      -> stdlib only (shells out to the above via subprocess)
#
# WHY THIS FILE EXISTS: the repo's only dependency manifest was
# microduck-software/repo/pyproject.toml, which describes the TRAINING env
# (microduck-mjbatch: mujoco / torch / mjbatch) and does NOT declare onnx. A fresh
# `git clone` + `uv sync` therefore could not re-run the bundle/rehearsal gates, so the
# "deploy-ready" verdict was not reproducible. This file pins the verification toolchain
# separately from training.
#
# INSTALL (from this directory):
#   python -m pip install -r requirements.txt
#   # or, with uv:
#   uv pip install -r requirements.txt
#
# NOTE (Pass12 sandbox): `onnx` could NOT be pip-installed in the audit sandbox
# (configured index returned "from versions: none" -- network/proxy restricted), so the
# install line below is declared-but-unverified in that environment. The packages are
# correct for the tools' imports; verify on a machine with PyPI/relevant mirror access.
