# Microduck：成本最低、效果最好的方案

> **本文结论在 2026-10-23 晚被社区实测账单推翻了一部分，已改写 §1 / §2.5 / §7。**
>
> 原结论是「任何自己攒的路线，要么比整机贵 2–4 倍，要么做出来是另一台机器」。
> 现在这句话只对 **XL330** 和 **STS3215** 成立。第三条路 ——
> **飞特 HD-1910-C001（¥99/颗）** —— 整机 **¥2234**，比官方整机（¥2850）还便宜，
> 而且是同样的 25 cm / 15 舵机规格。它之所以能成立，是因为它 21 g，
> 而 STS3215 是 55–60 g：§2 那条"便宜舵机必然导致整机放大"的推理，
> 前提是"便宜 = 重"，HD1910 打破了这个前提。

## 2.5 HD1910 为什么能推翻 §2（三个数字）

§2 的推理链是：*便宜舵机 → 必然重 → 整机必然放大 → 做出来是另一台机器*。
这条链的第二环对 STS3215 成立，对 HD1910 不成立：

| | XL330-M288-T | STS3215 | **HD-1910-C001** |
|---|---|---|---|
| 重量 | **18 g** | 55–60 g（**3.1×**） | **21±2 g（1.17×）** |
| 尺寸 | 20×40×27 mm 级 | 更大 | 34×20×23 mm |
| 6 V 堵转 | 0.92 N·m 级 | 1.86 N·m | 1.18 N·m（12 kg·cm） |
| 7.4 V 堵转 | — | — | **1.47 N·m**（15 kg·cm） |
| 编码器 | 磁编码 | 磁编码 | 12 位磁编码，0.088° |
| 单价 | ¥220–456 | ¥60–70 | **¥99** |

**HD1910 只比 XL330 重 17%，不是 3 倍。** 所以 25 cm 的机体不用放大。
飞特官网把它直接标成「**4.8V 9kg.cm 开源机器鸭专用舵机**」，就是这个意思。

代价（必须写清楚，不是白拿的）：
- **指令集不同**。物理层兼容（TTL 半双工、3 针），但 Dynamixel Protocol 2.0 的寄存器表、
  控制模式、反馈格式全不一样，`rustypot` 那套不能直接用。
- **没有官方权重**。所有现有 ONNX 都是在 XL330 + BAM 模型下训的，换舵机必须重训。
  国内已有 `kissqy/Microduck-kissqy`（¥2234 账单、自制 HAT/IMU、系统镜像）、
  `zhuoligetu123/microduck-hd1910m`（15×HD1910M + BNO08x，行走/拾取/起身/翻滚四模型）、
  `Ley-WL/microduck-rl`（HD1910 的 RL）在趟这条路，但都还不是"官方验证过"的状态。

## 2. 为什么"把便宜舵机塞进 25 cm"对 STS3215 不成立

这条对 STS3215 依然成立，值得保留，因为它是**同一个人试过的**。


STS3215 单价 ¥60–70，是 XL330（约 ¥299）的 **1/5**，力矩还更大（1.86 N·m vs 0.96 N·m）。看起来是显然的降本方案。

**但它重 3 倍（约 55–60 g vs 18 g）。** 实测后果：

| | 舵机 | 整机质量 | 身高 |
|---|---|---|---|
| Microduck | XL330 | 737.2 g | 25 cm |
| Open Duck Mini v2 | STS3215 | 2107.1 g | **42 cm** |

**2.86 倍。** 而 ODM v2 的作者 Antoine Pirrone 正是 **Pollen 的 R&D 工程师**——同一个人、同一个双足鸭架构，换了舵机之后**整台机器只能做成 42 cm、2.1 kg**。

**换句话说：如果你真的用便宜舵机复刻，"Microduck 复刻"会自动变成"再造一台 Open Duck Mini"，而 ODM v2 的 BOM 官方标的也是 $400。**

更进一步，参数是数量级差异（MJCF 里进仿真的值）：

| 参数 | XL330 | STS3215 | 差距 |
|---|---|---|---|
| `kp` | 0.55 | 17.8 | **32×** |
| `forcerange` | ±0.96 N·m | ±3.35 N·m | 3.5× |
| `damping` | 0.053 | 0.60 | 11× |
| `frictionloss` | 0.0048 | 0.052 | 11× |
| `armature` | 0.0018 | 0.028 | 15.5× |

**这不是微调，是两种不同的执行器。** 任何"改舵机但不重训"的想法在这里都会失败。

## 3. 推荐方案 A：保住官方权重，三段式 ¥3200–4100

> 想要 **HD1910 的 ¥2234 路线**，直接跳 §7 的路线 B。本节是"不重训"的那条，
> 代价是贵约 ¥1000，好处是官方 9 个 ONNX 策略可以直接用。

### 阶段 0 — 今天开始，¥0

**目标：不花一分钱，把 sim2real 全链路跑通，训出一个真正能走的策略。**

必要条件：一台能跑 Python 的电脑。**不需要 GPU**——这是本方案最省的地方。

```bash
git clone https://github.com/tailong-wu/microduck-mjbatch
cd microduck-mjbatch
uv sync
uv run train_ppo.py --task velocity --num-envs 4096 --iterations 1500 --timestep 0.005
uv run scripts/render_policy.py --policy microduck_policy.pt --command 0.4,0,0
```

**实测结果（8 vCPU，作者机器上的 RTX 2080 Ti 全程没用）：**

| 项 | 数值 |
|---|---|
| 墙钟时间 | **2 小时 36 分** |
| Final reward | 4.10 |
| 速度跟踪精度 | **0.95** |
| 摔倒 | **0 次** |
| 行为 | 要 0.3 m/s 走 0.21 m/s；不要求就站着；要求转就原地转 |

为什么选它而不是那 46 个训练栈里的别的：
- **不需要 GPU**，没有 CUDA 环境配置的一堆坑
- **命令只有两条**，没有 mjlab 那套多阶段课程
- 结果**被明确标注为 solved**，且给出了跟踪精度和摔倒次数，不是"看视频觉得能走"

**第二阶段（同一天，还是 ¥0）：把"能不能算数"这件事做实**

```bash
# 用官方策略的观测/动作对，校验你自己的实现
# craigm26/microduck-policy-golden-vectors
```

这是整个生态里**唯一能客观证明"我复现对了"的方法**。没有它，你只能靠视频判断，而视频会骗人——这是社区反复踩过的坑（`microduck-kick` 就是因为任务只在 70° 才算摔，PPO 稳在 57° 骗过了判定）。

**第三阶段（还是 ¥0）：看效果**

用官方浏览器沙箱（MuJoCo 编译成 WASM + onnxruntime-web，跑的是真策略，50 Hz），直接拖进你训出的 ONNX。不用装任何东西。

**阶段 0 产出**：一个能走的 ONNX + 一套完整的 sim2real 认知。**成本 ¥0。**

---

### 阶段 1 — 可选，¥300–600

**只在你真想摸硬件时做。**

买 **1 个 XL330**（约 ¥299），跑 Microduck 官方自带的 `xl330_test_bench`——那是真舵机标定台。

你会亲眼看到：
- 你算出来的 `kt`/`R`/`armature` 和 BAM 参数库里的是不是一致
- 齿隙在真实舵机上长什么样、为什么观测要"穿过"它去读
- `delay_lag` 那 3–6 个控制周期在示波器上是什么形状

**这是性价比最高的一次花钱**：¥299 买到的理解，比买 15 个舵机攒整机多得多。而且这些舵机以后装整机也用得上。

---

### 阶段 2 — 12 月，¥2850–3600

**买官方整机，把阶段 0 训的 ONNX 部署上去。**

理由很硬：
1. 价格比自己攒（¥2500–3000）几乎相同
2. 开箱能走，有 10 个官方策略兜底
3. 你阶段 0 训的策略可以直接热插拔——官方那套 61 维观测契约就是为了这个设计的
4. 不需要你解决装配公差、舵机 ID 分配、零点标定这一堆琐事

**注意一个坑**：官方的 walk-and-get-up 复合技能**依赖私有 teacher checkpoint**，没有它命令返回 HTTP 403。所以"从零复现官方最好的策略"这条路是堵的。但社区已经有人（`xinhuagu/my-microduck-journal`）重建了 teacher，产出了 `velstand_default` / `velstand_fast`，还有一个官方没有的 `sideroll.onnx`（侧滚一圈再起，768 只鸭 98% 成功）。**用他的，别自己从零啃。**

## 4. 替代方案：如果你现在就要一台真机

那就**不要复刻 Microduck**，直接做 **Open Duck Mini v2**：

- 舵机 ¥65×15 ≈ ¥975（国内现货，不像 XL330 要溢价）
- BOM 官方标 < $400
- 有 **Onshape 可编辑 CAD**、装配指南、中文 BOM 镜像
- **BAM 参数库里有官方辨识好的 `feetech_sts3215_7_4V`**，不用自己辨识
- 机械许可能商用（Microduck 的 NC 不行）
- 42 cm / 2.1 kg，比 25 cm 更容易装配调试

**代价**：它是另一台机器，Microduck 的训练配方和策略不能直接用。但它能真的站起来走。

## 5. 明确不要做的三件事

**① 不要用 XL330 现货溢价复刻。**
¥9700–11000，是整机的 4 倍，纯溢价，无技术收益。

**② 不要试图把便宜舵机塞进 25 cm 的机身。**
同一个人试过了，只能放大到 42 cm。这会在你装配到一半时才发现，代价是整个结构件重打。

**③ 不要从零复现官方的复合技能（walk + get up）。**
需要私有 teacher checkpoint，官方命令无 checkpoint 时返回 **HTTP 403**。用 `xinhuagu` 的产出。

## 6. "效果好"怎么算数

不要用视频判断。这个生态里有三个客观尺子：

| 尺子 | 用途 | 来源 |
|---|---|---|
| **Golden vectors** | 校验你的实现和官方逐位一致 | `craigm26/microduck-policy-golden-vectors` |
| **开放考试**（256 随机鸭 × 3 seeds） | 横向比策略：起身、抗推、速度、转向、body 指令、走到目标 | `xinhuagu/my-microduck-journal` 的 `docs/benchmark.md`，**官方策略在同一张表里** |
| **Arena 官方榜** | 只跑官方赛道（2 m 冲刺 / 滑板 / 爬坡） | 服务端 5 seeds × 全速度扫频重跑 |

**注意一个已被证实的陷阱**：官方的 `error_vel_xy` 指标**高估约 3 倍**（混了 5 种指令模式，还包含 reset 爬升段；逐帧稳态误差 0.07，日志却记 0.206）。所以看到任何"误差 0.2"的数字，都要先问它是在什么口径下测的。

## 8. 一句话

**这个项目最贵的不是硬件，是"用错硬件浪费的时间"。**

先用 0 元把链路跑通——你会发现真正难的是奖励设计和 sim2real，不是钱。跑完再决定要不要买机器，

愿意 → HD1910（¥2234）；不愿意 → 官方整机（¥2850 起）。
