# 国内自制 Microduck：四条开源路线的真实底细

> ## ⚠️ 本文结论已被证伪（2026-10-23 晚更正）
>
> **第 1 节把宇树 S288 排第一，理由是「0.6 N·m、比 XL330 扭矩更大」——那个数字是错的。**
> 宇树官网桌面版参数表自己写着：S288 堵转扭矩 **反向 0.2 N·m / 同向 0.07 N·m**，最大线电流 0.32 A，
> 扭矩常数 0.554 N·m/A → 0.554 × 0.32 = **0.177 ≈ 0.2 N·m**，自洽。
> 而 XL330 在真机上被超压到 6.6–8.2 V 运行（官方 HAT 原理图里舵机脚直连 `+BATT`，无稳压），
> 等效约 **0.83–0.96 N·m**。**S288 不是「更便宜且扭矩更大」，是「扭矩 1/4」。**
>
> 另两条也站不住：飞特 STS3032 额定扭矩只有 0.147 N·m；STS3215 会做到 42 cm。
>
> **唯一可行路线见 `microduck-硬件方案.md`：原版 XL330-M288-T ×15 + Radxa Zero 3W + 一条 1 Mbps 总线。**
> 本文其余部分（各仓库的成熟度、资料完整度、价格清单）仍然有效，可当参考资料读。

> 前提变了：官方整机 $399 国内买不到，只能自己做。
> 那核心问题就变成——**用哪种舵机，还能保住 25 cm 的体型？**
> 这份报告把四条路线的舵机规格、成熟度、可下单程度、真实成本全查了一遍。
> 数据取自各仓库 README / BOM / 官方规格页，检索日 2026-10-23。

## 1. 关键发现：S288 是唯一能保住 25 cm 的国产舵机

这是整份报告最重要的一条。

之前算过：用飞特 STS3215 降本，会因为它重 3 倍（55–60 g）导致整机被迫放大到 42 cm。**但宇树 S288 不一样。**

| 参数 | **XL330-M288-T** | **宇树 S288** | 差异 |
|---|---|---|---|
| 重量 | ~18 g | **19.5 g** | **+8%，几乎相同** |
| 尺寸 | 20 × 33.5 × 26 mm | **20 × 34 × 26 mm** | 几乎相同 |
| 减速比 | 288:1 | **288.35 : 1** | 同一档 |
| 堵转扭矩 | 0.39 N·m @5V（额定） | **0.6 N·m @12.6V** | **更大** |
| 空载转速 | — | 16.5 rad/s（157 rpm）@12V | — |
| 编码器 | 12 bit 绝对 | **15 bit 双绝对**（转子端 + 输出端） | 更好 |
| 通信 | TTL 半双工 | TTL 半双工 **6 Mbps** | 更快 |
| 电压 | 5–6 V | **6.4–12.6 V**（推荐 12.6V） | 更宽 |
| 控制模式 | 位置 | 位置 + **混合力控**（扭矩/刚度/阻尼） | 更多 |
| 齿轮 | 塑料 | 工程塑料（J288 是钢 + 铝壳，39 g） | — |
| **单价** | **¥299（官方）**<br>现货溢价约 ¥650 | **¥159（京东宇树旗舰店）** | **便宜一半** |
| ID 范围 | 0–253 | **0–14**（正好 15 个） | 够用 |

**S288 明显是对着 XL330-M288 做的国产对标件**——同样的 288:1 减速比（名字里的 288 就是它）、同样的 20×34×26 尺寸、同样的 19.5 g 重量，但扭矩更大、编码器更好、价格一半。

**这是国内自制 25 cm 机器鸭的唯一合理舵机选择。**

## 2. 方案①：AI-FanGe（最省事，推荐先看这个）

**`AI-FanGe/Microduck-build-tutorial`**，1352★，中文，有实机行走视频。

### 为什么它排第一

**它提供了一个可直接刷写的预构建镜像** `microduck.img.xz`：

- Raspberry Pi OS Lite 64-bit，主机名 `microduck`，默认用户 `user`
- 部署目录 `~/microduck`，Python venv 已建好
- **行走模型已内置**：`~/microduck/src/agents/walk.onnx`
- 无头手柄服务 `microduck-gamepad.service`，可开机后用手柄启动模型

**你刷完卡、接好线，就能走。** 这是四条路线里唯一做到这点的。

### 完整 BOM（作者给的）

| 类别 | 物料 | 数量 | 说明 |
|---|---|---|---|
| 控制板 | Raspberry Pi Zero 2 W | 1 | 跑控制程序、蓝牙手柄、Wi-Fi/SSH |
| 舵机控制板 | **ROBOTIS OpenRB-150** | 1 | USB 接 Pi，挂 XL330 总线；代码自动找 `/dev/serial/by-id/usb-ROBOTIS_OpenRB-150_*` |
| 舵机 | **Dynamixel XL330-M288-T** | **14** | 双腿 10 + 头颈 4；嘴是 ID 15，走路模型不依赖 |
| 电池 | 成品 6V 可充电池 | 1 | 不用两节 18650 自制；注意瞬时电流 |
| 开关 / 存储 | 电源开关 / ≥16GB microSD | 1 / 1 | 新卡，首启自动扩分区 |
| IMU | BNO080 / 085 / 086 | 1 | I2C，自动探测常见地址 |
| 结构件 | 3D 打印件 | 1 套 | `microduck/cad/`，推荐 PLA |
| 紧固件 | M2 / M2.5 自攻螺丝 | — | — |

**注意一个省钱细节：它只用 14 个舵机，不是 15 个。** 嘴部舵机（ID 15）走路用不到，省 ¥299。

| 14 × XL330 | ¥4186 | ¥9100 |
| OpenRB-150 | ¥350–450 | 同 |
| Pi Zero 2 W | ¥150–200 | 同 |
| 6V 电池 + 开关 | ¥120–180 | 同 |

**XL330 的价格是唯一的变量**，也是这个方案最大的风险：官方指导价 ¥299，但国内现货常溢价到 ¥650 左右。

## 3. 方案②：fanduck（资料最完整，含 PCB 制造文件）

**`7757/fanduck`**，67★，**已经复刻成功**，有实拍照片 + 两段实测视频（12 秒、19 秒）。

### 它比 AI-FanGe 多什么

资料版本 `maker-20260916`，四个 ZIP，**带 SHA256 校验和 manifest**：

| 资料包 | 内容 | 大小 |
|---|---|---|
| 制作物料与打印文件 | **物料清单、中文分类打印件、装配图** | 12.7 MB |
| **板件制造资料** | **Robot HAT、电池触点板、NFC 图纸及制造文件** | 31.3 MB |
| 制作工具源码 | 打印修正版生成、几何检查脚本 | 1.1 MB |
| 3D 镜像工作台源码 | 3D 姿态显示、只读关节采集 | 2.6 MB |

**"板件制造资料"这一项是关键。** 官方明确不开源硬件（no BOM、no CAD、no PCB），而这块 **Robot HAT** 正是复刻者最缺的板子。fanduck 把制造文件放出来了。

### 成本

15 个 XL330：¥4485（官方价）/ ¥9750（溢价），其余同方案①。
**合计 ¥5300–5800 / ¥11000+。**

比 AI-FanGe 多一个舵机、多一块板，但也多了 PCB 制造文件和装配图。

**建议：两个都下，用 fanduck 的装配图和 PCB 资料 + AI-FanGe 的镜像和 cad 目录。**

## 4. 方案③：S288（舵机最便宜，但还不能直接开工）

**`zj281136/microduck-s288`**，中文，5 篇教程，**保留原鸭头**。

### 它有什么

- 15 个 S288（14 个关节参与 RL）
- Pi Zero 2 W + **宇树官方 USB 电机通信板**（UniArm L1 同款）
- LSM6DSV16X IMU
- 3S 航模锂电 + Y 型分线 + 12V→5V 降压
- **不需要自己画 PCB、不需要焊接电路**
- 训练代码、仿真模型、标定工具、部署程序、**一份预训练 ONNX**
- 使用 **S288 的 M1 BAM 执行器配置** + 传动间隙随机化
- 文档质量极高：区分"转子位置"与"输出端位置"，明确说 `0.55 N·m 限幅只是训练配置，不是厂家额定扭矩`

### 但它现在还不能下单

这是我要说清楚的最重要一点。它的 **BOM 全是 `TODO`**：

> "型号、价格和链接没核实的地方保留 `TODO`，不会先填一个估计数；未知价格也不计作零成本。"
> "在型号、紧固件和供电路径未选定前，不给出整机总价。"

而且：

- **`print/README.md` 只有一句话**——指向 `laotawayer/microduck` 的 release，**打印件不是它自己的**
- BOM 里 `F01 printed = "Original-head S288 print set, print-ready revision/parts quantities TODO"`，**打印套件还没定版**
- README 自述：待补视频；装配细节、零位参考、完整复现记录还在更新

**所以它是一条"方向已被验证、但还不能照着下单"的路线。** 态度值得尊敬（宁可留 TODO 也不编数字），但对你现在动手不利。

## 5. 方案④：ODM v2（真正最便宜，但是 42 cm）

**`apirrone/Open_Duck_Mini` v2**，4371★，用飞特 **STS3215**（¥65/个）。

- 15 个舵机 ¥975
- **BAM 参数库里有官方辨识好的 `feetech_sts3215_7_4V`**，不用自己辨识
- Onshape 可编辑 CAD + `onshape-to-robot` 一键导出 URDF/MJCF
- 公开 BOM（含中文飞书镜像）+ 装配指南 + 打印指南
- 机械许可可商用（不像 Microduck 的 NC）
- 有社区现成的完整 sim2real 教程

**总成本 ¥2000–2500**，是四条里最便宜的。

**代价**：42 cm / 2.1 kg，是**另一台机器**，Microduck 的训练配方和策略不能直接用。

## 8. 我的建议

**如果你现在就想让它走起来：**
走**方案①+②组合**——用 AI-FanGe 的镜像和 `cad/` 目录，配 fanduck 的装配图和 PCB 制造文件。成本 ¥5100 起（XL330 按官方价）。这是唯一"今天下单、两周内能走"的路径。

**如果你能等一两个月，且想把成本砍到三分之一：**
盯 **S288**。它的方向已被实物验证，文档质量是全线最高的，缺的只是"定版 BOM + 打印件"。它现在的 `TODO` 大概率会在未来几周被填上（作者在小红书有群，二维码有效期到 2026-11-13）。

**如果你只是想要一台能走的双足，不在乎是不是"鸭"：**
做 **ODM v2**，¥2000–2500，资料最全，还能商用。

**三条不要做的事：**
1. **不要按 XL330 现货溢价下单**（¥650/个），先问 ROBOTIS 官方渠道或等补货，¥299 和 ¥650 差 ¥5000
2. **不要照抄 zhuoligetu123 的原始接线图**——作者本人标注了端子连线错误
3. **不要试图把 STS3215 塞进 25 cm 机身**——会变成 42 cm，同一位工程师试过了

## 9. 一个提醒

四条路线里，**没有任何一条有"完整可下单 + 已验证 + 最便宜"的三角**：

- 能下单的（AI-FanGe / fanduck / ODM）→ 舵机贵，或者体型不对
- 舵机便宜的（S288）→ 下单清单还没写完
- 已验证的（fanduck / AI-FanGe / ODM）→ 都是 XL330 或 STS3215

**这不是巧合，是国内供应链和这个特定项目的错位**：官方那颗 XL330 在 18 g 里做到了 288:1 减速比 + 编码器 + 驱动器 + 总线菊花链，国内目前只有宇树 S288 做到了同样的集成度，而它还没被完整走通过一遍。

**这就是真实的空白所在。** 谁把 S288 那条路走完并留下可下单的 BOM，谁就补上了国内这个生态最缺的一块。
