# 拼出一只完整的 MicroDuck（飞特 HD-1910 / v2.2）

> # 🔴 本文结论已作废（2026-11-06 当日更正）
>
> 后续做「两版整机装配完整性核对」时逐一实测发现：**3MF 里 33 个网格的中心全部是 (0,0,0)**，
> 它们是「以零件自身中心为原点」的**局部坐标**，不是整机装配位姿。因此本文所称的
> `microduck_assembled.stl` 实际是 **33 个零件全部重叠堆在原点的一坨**，不是拼好的鸭子。
> 当时把「各零件包围盒的并集 91.8×122.7×83.5 三轴铺开」误判成「整机占位」，这是判据错误。
>
> - **§1 / §2 / §6 全部作废**；`microduck_assembled.stl` 请勿使用。
> - 3MF 的 43 个 `<build>` transform 是 Bambu 摊开陈列位姿（X 17–816 mm、16 个实例 Z<0），
>   `assembly_model.json` 的 `offset_to_assembly` 全为 `[0,0,0]`，**均不是整机位姿**。
> - 整机精确位姿只在 SolidWorks `.SLDASM` 专有二进制里，本机无法解析。
> - 正确结论与可验证的两版零件包见

_2026-11-06。回应「试试看能不能拼出一个完整的鸭子」——**能，已拼出**（❌ 此判断已作废，见上方更正）。本文记录怎么从作者 CAD 仓库的 3MF 把 33 个打印件合体成一只完整鸭子的几何，并给出验证与查看方式。_

## 1. 结论（❌ 作废）

- ✅ **33 个打印件已合并为一个整机 STL**：`out/microduck_replica/microduck_assembled.stl`
  - 33 件 / 391,346 三角面 / 19.5 MB / 单位 mm
  - 包围盒：X 91.8 × Y 122.7 × Z 83.5 mm（三轴都铺开，是只站着的鸭子，不是零件乱堆）
- ✅ **验证**：作者仓库的整机渲染图 `组件图/00-microduck装配体.png` 与 3 张爆炸图，几何与本文合体一致；BOM 写明「33 项打印件」，与合并件数吻合。
- ⚠️ 这是**结构鸭**（33 个塑料/金属打印件）。15 颗舵机、电池、各 PCB、IMU、摄像头是外购件，不在此 STL 内（见 §5）。

## 2. 为什么能"直接拼"——关键判定

来源：`fanhao375/microduck-replica-cad` 仓库的 `打印/microduck-飞特版-BambuStudio2026-11-02.3mf`（5.2 MB，飞特 HD-1910 v2.2 / 11-02 更新版）。

- 3MF 内每个零件网格在 `3D/Objects/object_*.model`，**已经带世界坐标**——主模型 `3D/3dmodel.model` 里每个 `<component>` 的 transform 实测是**单位阵**（仅 -2e-16 的 z 偏移）。也就是说作者建模时零件就摆在装配位，导出后坐标没动。
- ⇒ 把 33 个有网格的 `object_*.model` 按**原始顶点**直接合并，得到的就是整机。
- 注意仓库里还有 `Metadata/assembly_model.json` 的 `assemble_transform`——那套变换是把零件**摊开成爆炸图**的装配说明位（X 坐标铺到 49 / 212 / 551… 跨度 ~550 mm），**不是整机位姿**，所以合体时不用它。
- 三套 UUID（零件文件 / 组件 / 装配叶子）互不相交，叶子用的是 Bambu 内部 volume id，无法用来做映射；因此改用「直接合并原始顶点」这条最稳的路径。

## 3. 怎么生成的

脚本：`out/microduck_replica/assemble_duck.py`（纯 Python，无外部依赖）
1. 解 3MF（zip）→ 读所有 `object_*.model`，正则解析 `<vertex>` / `<triangle>`；
2. 跳过 10 个 406 字节的空对象（无网格），保留 33 个有网格的件；
3. 逐三角面计算法线、按原始坐标写入二进制 STL。

```bash
cd out/microduck_replica && python assemble_duck.py
# parts=33  triangles=391346
# bbox X[-45.9,45.9] Y[-61.3,61.3] Z[-41.7,41.7]
# size X=91.8 Y=122.7 Z=83.5 mm
```

## 4. 15 组件装配顺序（来自作者 README）

整机装配基准是 **01 躯干主体**，按 01→15 依次装：

```
1. 01 躯干主体          —— 整机基准，先固定
2. 02→06 左腿           左髋 → 左髋Roll → 左大腿 → 左小腿 → 左踝脚
3. 07→10 颈头           颈根 → 颈俯仰 → 头Yaw/Roll → 头部总成
4. 11→15 右腿           右髋 → 右髋Roll → 右大腿 → 右小腿 → 右踝脚（与左腿镜像）
```

每个组件的单独图见 `组件图/0X-*.png`（01 躯干主体 … 15 右踝脚），爆炸图见 `组件图/00-microduck装配体爆炸图1~3.png`。

## 5. 这只在"几何"层面完整，实物还差什么

STL 只含 33 个结构打印件。真机要动起来还需外购件（BOM 24 项，硬件成本约 2900 元）：

| 类别 | 关键件 | 备注 |
|---|---|---|
| 执行器 | 飞特 HD-1910 ×15 | 凸盘，与 XL330 配合件不通用 |
| 主控 | Radxa Zero 3W + 64GB TF | 实机主控（外形同 Pi Zero 2W） |
| 电控 | kissqy RPI_Robot_HAT / imu_to_dxl / hub 分线板 / URT-2 | 见 `microduck-双版本推进-*.md` |
| 能源 | NP-F550 电池（**不是 NP-F970**） | 文件名沿用上游 `np_f970`，实物是 F550，买错装不下 |
| 传感 | IMX219 摄像头、VL53L5X ToF | 头/脸部位 |
| 标准件 | 轴承 10×15×3 / 16×22×4 / 6×12×3、M2/M2.5 螺丝、螺纹胶 | 轮滑变体还需合体轮胎(TPU) |

## 6. 怎么看这只鸭子

- **几何文件**：`out/microduck_replica/microduck_assembled.stl`，用任意 STL 查看器（PrusaSlicer / Blender / 在线 viewer）打开。
  - 坐标：导出时 **Y 轴约 123 mm 为上**（部分查看器默认 Z 上，看到是侧躺的鸭子，旋转一下即可）。
- **作者渲染图 / 爆炸图**：`组件图/00-microduck装配体.png`、`00-microduck装配体爆炸图1~3.png` —— 直接看成品长相和拆解。
- **21 页装配说明书**：`安装说明书/microduck装配安装说明书.pdf`，逐步图文。
- **B 站视频教程**：机械行者Robo《MicroDuck 从零安装教程》合集（共 8 集，已更 6 集）。
