# MicroDuck 飞特版 3D 打印件 × Orange Pi Zero 3W 适配清单

_2026-11-06（多次更正）。资料源：本地 `fanhao375/microduck-replica-cad`（飞特版 v2.2，BOM 2026-10-23，33 打印件 + 23 外购件）、官方 orangepi.cn / orangepi.org 参数页、Orange Pi Zero 3W 引脚定义（playwithcircuit，2026-11-06 核对）。随 `docs/hardware/microduck-最优方案-价格硬件软件-2026-11-06.md` 一起看。_

## 0. 一句话结论（2026-11-06 终版，已多轮更正）

飞特版 v2.2 的 **33 个打印件里，31 件与主控板无关，可直接用**。Orange Pi Zero 3W 分支：
- **电气层：HAT 实际可直插**（详见 §附录 引脚对照）。Orange Pi 40-pin 在舵机 UART(8/10)、IMU I2C(3/5)、5V/3.3V、GND 上**与 RPi 同脚位一致**——早先"40-pin≠RPi、HAT 不能直插、IMU I2C 失效"的判断**已证伪**。
- **机械层：真约束是躯干主壳控制器型腔的"深度"**。~32mm 的内腔深度对 Radxa(30mm 板) 仅余 ~2mm、对 Orange Pi(32mm 板) 几乎 0 余量（取决于 SBC 在主控腔里的实际朝向，见 §5）。这是唯一需要现场/实测确认、或做小改的地方。

> 📌 **更正时间线（保留以便追溯）**
> 1. 初版（已被推翻）：以为"`trunk_base` 是 SBC 卡位、Orange Pi 仅多 2mm 宽余量待核"。
> 2. 第 1 次更正：读 README+躯干图发现 `trunk_base` 是髋 yaw 舵机位、SBC 在**躯干主壳型腔**；并误以为"40-pin 不兼容 HAT = 电气死穴"。
> 3. **第 2 次更正（本次，关键）**：拉到 Orange Pi Zero 3W 官方引脚定义，发现 40-pin **功能与 RPi 一致**，HAT 可直插；电气关不存在。真约束收敛到**腔体深度 ~32mm** 这一项机械量。
> 4. 另：GitHub Releases **没有** 418MB STEP 包（只有软件更新 ~10–62MB 与 755MB 系统镜像 .img.xz），故腔体尺寸改从本地 3MF 网格实测，不再依赖那份不存在的 STEP。

> 顺带收口一个矛盾：作者 CAD 的板模型命名 `pcb__raspberry_pi_zero_2_w`，但仓库 README 明说「实机主控是 **Radxa Zero 3W（RK3566）**」。也就是说 **fanhao375 这套事实标准机械件，本来就按 Radxa Zero 3W 建**——跟"最优方案 = Radxa Zero 3W + 官方 Apache-2.0 fork"完全对齐。Orange Pi 分支只在你明确要 A733 的 NPU 时才值得。

## 1. 换 Orange Pi 到底变什么（终版）

| 维度 | Radxa Zero 3W（作者实机） | Orange Pi Zero 3W（A733） | 对 3D / 硬件的影响 |
|---|---|---|---|
| 板型 | Pi Zero 2W 板型，65×30 mm | 65×32×1.2 mm（官方中文参数页） | **机械：板宽多 2mm** |
| 安装孔 | Pi Zero 2W 四孔位 | 评测确认「identical hole spacing」 | 孔距一致；是否真能利用取决于主控腔朝向 |
| 40-pin | RPi 兼容 | **功能与 RPi 同脚位一致**（UART 8/10、I2C 3/5、5V/3.3V、GND 全同） | **电气：HAT 可直插**（见附录）；早先"不能直插"已证伪 |
| 真约束 | — | 躯干主壳控制器型腔深度 ~32mm vs 板宽 32mm | **机械：腔体深度余量**，唯一需实测/小改处 |

**判定**：Orange Pi 分支的"不兼容"从"电气死穴"降级为"机械上腔体深度 +2mm 的微调"。HAT 电气兼容，无需重做 PCB。

## 2. 33 打印件逐类判定（修正 SBC 安装位）

判据口径：**"随主控板变" = 该件几何取决于 SBC 板型 / 主控腔尺寸 / 摄像头接口**。

| 类别 | 件 | 是否随板变 | 判定 |
|---|---|---|---|
| 头壳 / 面部 | 头部上壳(1)、头部下壳(2)、面部零件(3,含 -FT1 瑞莎摄像头变体)、下巴(4)、软下巴(5)、软嘴顶部(6)、眼睛(7) | 部分 | **直接用**；仅 `face_part` 可能因摄像头换型核孔距 |
| 颈 | 颈部(8)、颈部俯仰(9) | 否 | **直接用** |
| 躯干 | 躯干底座(10)=髋 yaw 舵机位、左右壳(11/12)、电源支架(31)、香蕉形PCB锁扣(32) | 否 | **直接用**；`trunk_base` 是舵机位不是 SBC 位 |
| 腿 / 髋 / 踝 / 脚 | 髋部左(13)、偏航转横滚(14)、偏航横滚运动(15)、腿部(16)、左上/右上腿(17/18)、上腿加固板(19)、左/右脚(20/21)、左/右脚底(22/23)、脚踝左/右(24/25)、脚踝左/右V1(26/27)、轴承滚轮(33) | 否 | **直接用**（飞特版舵盘配合件） |
| 轮滑 / 转接 | 合体轮胎(28)、滚轮叶片(29)、电机支架(30) | 否 | **直接用** |
| 主控腔所在件 | `01 躯干主体`（torso 主壳） | **弱相关** | **大概率直接用**；仅当 Orange Pi(32mm) 在腔体深度方向卡住时，需把该件腔体深度放宽 2–3mm（"放宽"不是"重做"） |

**汇总**：33 件 → 31 件直接用；唯一可能与 Orange Pi 相关的只有 **`01 躯干主体` 的主控腔深度**，且是局部放宽而非重做。33 件中**没有**"固定 SBC"的专属打印件——SBC 由躯干主壳腔体 + 作者设计的支架卡住。

## 3. 真正要解决的（机械 + 软件，不是电气 HAT）

BOM 第 3 项「树莓派机器人HAT电路板」按 RPi 40-pin 设计，**Orange Pi 40-pin 功能同脚位 → 可直插**，无需重做 PCB。剩余工作：

| 项 | 内容 | 性质 |
|---|---|---|
| **A（真约束·机械）** | `01 躯干主体` 主控腔深度 ~32mm：Radxa(30mm) 余 ~2mm，Orange Pi(32mm) 近乎 0 余量。需按 SBC 实际朝向确认，若卡住把腔体深度放宽 2–3mm（改 1 个件） | 3D 小改，可用网格实测 + 实物确认 |
| **B（软件）** | Orange Pi 上需启用 UART0（舵机总线，Pin8/10）+ TWI0/I2C（IMU，Pin3/5），通常 armbian-config 开 overlay；核对设备名（如 `/dev/ttyS*`）与 robotd 配置一致 | Linux 配置 |
| **C（电源预算）** | Orange Pi 40-pin 5V(2/4) 与 RPi 同，但 A733 功耗/NPU 负载下 5V 轨带载能力需实测，HAT 伺服 5V 由板供 | 上电实测 |

> 结论：**不再需要"重做 HAT / 绕开 40-pin"**。Orange Pi 分支的性价比 = "把躯干主壳腔体深度放宽 2–3mm + 软件开 UART/I2C"，远小于早先预估的 PCB 重做。

## 4. 我已有的"载板"（⚠️ 思路已弃，勿直接打）

`cad/orangepi_zero3w_carrier.scad` / `cad/orangepi_zero3w_carrier.stl` 是按**外挂耳板**（69×36、带耳 89mm，M3 长圆孔拧躯干外侧）建的。经两轮更正后确认：
- 它解决的是"外挂固定"，而正确做法是 **SBC 像作者那样整栈进躯干主壳腔体**（HAT 已兼容，无需外挂）；
- 它比裸板还大、且**没有解决真约束（腔体深度）**；
- 在 Radxa 路径下完全不需要；在 Orange Pi 路径下也不能救场。

**处置**：该载板降为"外挂固定草模"参考，不再作为 Orange Pi 适配的主方案。若最终选 Orange Pi 且确需外挂（而非改腔体），再据此重做尺寸。

## 5. 仍需现场核的未知项

- **SBC 在躯干主壳腔里的实际朝向**：决定 32mm 板宽到底卡在"深度"还是"宽/高"（后两者余量充足）。从网格测的胸高腔体外壳深 28–35mm（内腔约 24–31mm，按 ~2mm 壁厚估），但精确值需实物或 CAD。这是"2mm 是否真卡死"的唯一未定项。
- **Orange Pi 40-pin 与 RPi 的逐脚一致性**：本清单附录基于 playwithcircuit 引脚表，建议上机前再对照 orangepi.org 官方引脚图（本次 WebFetch 失败）核一遍，尤其是 Pin27/28（HAT EEPROM 自动识别用 I2C0，缺失只影响自动配置、不影响手动使用）。
- **真实安装孔数/孔径**：评测仅确认"孔距一致"，待实物或官方机械图二次确认。
- **板角倒圆半径**：官方未给，暂估 2.0。

## 6. 下一步

1. **选 Radxa Zero 3W**：33 件零改动，HAT 直插，本清单到此为止。
2. **坚持 Orange Pi**：① 用网格腔体数据 + 实物确认 SBC 朝向与深度余量；② 若卡住，把 `01 躯干主体` 腔体深度放宽 2–3mm（改 1 件，出可打 STL）；③ 软件开 UART0/TWI0；④ 上电按 Radxa 验收清单同类项核对（节点名、I2C、1Mbps 扫舵机）。
3. 交叉更新 `microduck-最优方案-价格硬件软件-2026-11-06.md` 的 §3.4：结论改为"Radxa 零改动最优；Orange Pi 电气已兼容，仅腔体深度 +2mm 微调"。

## 附录：kissqy HAT 40-pin 引脚对照（RPi ⇄ Orange Pi Zero 3W）

| 4 | 5V | 5V | ✅ | 伺服 5V |

| 9 | GND | GND | ✅ | 地 |
