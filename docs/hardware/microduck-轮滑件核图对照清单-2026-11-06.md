## 2. 对号必要性（为什么不可省）

1. **BOM 与 3MF 编号空间不同**（BOM 主目录 20–29 vs object_2x/3x），43 vs 42 的 1 差也藏在这里。
2. **Bambu 工程无零件名**（`3D/Objects/object_N.model` 只有路径），映射只能靠几何形状+装箱位置。
3. **滚轮叶片即可核对项**：上游 2026-07 起把刀片并入踝体——但 3MF 里它是独立网格，这正是要核的第一件事（见 P-B）。

## 3. 打勾判据（每条可独立验证）

### P-A 轮组：确认 object_297 四个实例 = 合体轮胎×4
- 判据一（尺寸）：30×30×7.6 mm × 4 个实例已在位——与轮形吻合。
- 判据二（形态，核心待核）：看图确认它是**单壁一体轮**（合体轮胎，v2.1 重磅）还是**两个叠片**（独立轮辋+轮胎两套 rim×4+tire×4）。
  - 若为单壁一体 → BOM 28（合体轮胎.stp，TPU ×4）直接用。
  - 若为两叠片 → 回改 BOM 28 打印说明 + 回改 `manifest_roller.csv`，并更新轮滑计划 §3 的"读数矛盾"条目。
- 开盘动作：在 Bambu 切片软件中选中这 4 个 object，检查壁厚/内壁结构；并核对它们位置是否呈"每腿前后两轮"（roller XML `tire×4` 结构）。

### P-b 叶片：确认 object_301 两个实例 = 滚轮叶片×2
- 判据：23×40×3.5 mm，位于 (486,-95)，与轮子（y≈-99）同层相邻——开口在脚踝下方。
- 关键判据：叶片上应有**轴孔/轴承座**（Ø≈12 mm 孔，与 BOM 外购 #16 的 6×12×3 轴承匹配，即内径 12 mm）。有孔 ⇒ 叶片坐实；无孔 ⇒ 待定。
- 附加动作：若 P-A 成立且 P-b 成立，可同时确认 3MF 里叶片是**独立实体**（而非合并进踝体）——更新 MEMORY 的"合并进踝"实现口径（那是仿真模型的写法，不一定是 CAD 实现）。

### P-c V1 备选踝：确认 object_281 两个实例 = ankle_l_v1 / ankle_r_v1
- 判据：23×25.8×20.5 mm，镜像对 (178,-274) / (222,-276)，位于腿端。
- 开盘动作：打开 3MF 装配序列，核对这两个网格的**脚掌方向狭缝/安装槽**是否与轮组/叶片接口吻合。

### P-d 走路件退出：foot/sole×2 在 43 实例中是哪 4 格？
- 方法：本页 §1 表里，没有精确对应"脚底"的网格被锁定；逐格过盘，凡在"脚踝位"（y < -250 的腿端网格）里未被 P-A/P-b/P-c 分配的，补登录 foot/sole 映射。
- 然后核对"走路件备件禁用"清单（轮滑计划 §7）可行性——即：轮滑装机时，这几格不打，但保留备件。

### P-e 其余镜像对×2（object_31/13/265/261/24）逐格过 → 归镜像族
- 判据：镜像对（±X 或 Z 对称）先归族，再按族内尺寸登录角色（参加 §2.1 的"每族一角色"）。
- 目的：把 43 格映射到 BOM 的 33 项打印件，收口 43-vs-42 差。

## 4. 第一轮打勾顺序（开盘图场景流）

1. **P-A 先核轮子**（判据最硬：4 格是否单壁+尺寸 30×30×7.6）⇒ 若独立 rim+tire ⇒ 回改轮滑计划 §3 与 BOM 说明；若合体 ⇒ 通过。
2. P-b V1 踝 + P-b 叶片（组合核：踝装轮 → 叶片轴孔与轮壁厚的接口校验）。
3. P-d 走路件退出 → 补轮滑"不装"清单（确认 foot/sole 4 格）。
4. P-e 其余镜像对 → 43 格 → 33 项 BOM 全映射（收口 43-vs-42 差，同时改 §5 里"1 差"条目）。
