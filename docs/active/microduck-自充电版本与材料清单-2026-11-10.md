_2026-11-10。承接 `microdock-真机本体改动清单-2026-11-10.md` 与 `microdock-v2-从硬件到训练-全链深研-2026-11-10.md`。本文只谈「充电这件事」——不碰视觉、不碰策略、不训练。价格是电商参考区间，未逐项询价。_

## 0. 本轮改写了上一轮一条硬判决

上一轮把「改主控 PCB 加 2S 充电管理」列为充电侧最硬前提。一手核实后发现两个事实，把它**降级**：

1. **唯卓仕 NP-F550「小布丁」自带 Type-C 直充口**，电池内部已含 2S 8.4V CC/CV 充电 + 9 重保护（过压/过流/过充/过放/过功率/短路等），5V/2A 输入、约 2h 满。
   来源：唯卓仕官网 F 系列页、台湾经销商页（明写「9 重電路保護」「Type-c 充電口 5V/2A」）、IT之家 2023-03 小布丁发布（¥99 一对）、syntex 产品页。
   ⇒ 充电 IC 在电池里，鸭子本体**不必为「充电 IC」改板**。
2. **三家电池厂一致明令「禁止边充边用」**：唯卓仕台湾站原文「正常使用情況為充電和放電分開，**請勿邊充邊用，會有過熱燒壞電池的危險**」；Viltrox / syntex 英文版「Do not charge the battery while using it」；FEEL WORLD FAQ「Powering a light while charging is not recommended」。
   ⇒ 官方 issue #470「开机带载充」在 NP-F550 上是**伪需求**：正解是**入坞即断主负载、关机充**。因此也不需要 BQ24610 那套 DPM / 电源路径管理（那是给边充边放准备的），TP5100 级纯 CC/CV 就够——省一片 PCB 和 ¥30+。

**判决不变**：视觉（已砍）决定「能不能自己找到坞」，充电决定「插上后能不能补电」，背部几何决定「磁头够不够得到」——三者正交。本轮只把充电这条从「改 PCB」降级为「加一对触点 / 一根线 + 坞内一个模块」，**不推翻任何既有裁决**。

### 语义先分清：「自动补电」≠「自主回坞」
用户说的「自充电」按「摆到位就自动补电」理解（延续上一轮 A 被动座）；要鸭子**自己找到坞再充**，是 V3，得把 2026-10-27 砍掉的视觉加回来，并给 butt-walk / sitstand 策略换 plant 重训。

**反直觉的一条**：V1 反而比 V2 机械更简单。NP-F 的正负主触点本来就在电池仓底（间距 28.5 mm），从它引线到背部母座是顺手的事；而小布丁的 Type-C 口在**电池侧面**，装进仓后被仓壁挡住，要够到它得在仓壁开窗（破坏结构/进灰）或飞线引出——比 V1 更绕。

## 2. 最容易买错的一处：充电模块的输入电压

| 方案 | 拓扑 | 输入 | 2S 能否出 8.4V | 充电电流 | 备注 |
|---|---|---|---|---|---|
| **TP5100** | buck 降压 | 4.5–12V（推荐 ≤9V） | ✅ 但**输入必须 >8.4V** | 0.1–2A 可调 | ⚠️ 拿 5V 充电头接它 2S = 完全充不进，白买 |
| **BQ24610** | buck 降压 + DPM | 5–28V | ✅ 同样需 >8.4V | 至 10A | standalone，FB 电阻设 8.4V（30K:10K）；带载充才用得上，本方案不需要 |
| **Adeept / DIANN Type-C 2S 板** | **boost 升压** | 5V | ✅ 5V 直进 | 0.55 / 1.1 / 2.2A 档 | 带 BMS，效率约 94%；慢但省事，能直接吃鸭子现有 5V 口 |
| **小布丁电池内置** | 升压/降压（厂做） | 5V/2A | ✅ | ≈1.1A（0.5C） | 连模块都省；受制于电池侧面口 + 25mm 厚 |

**buck 不能升压是硬物理**（datasheet 明标 switching step-down）。所以给两条清晰的路：

- **快（≈1h / 1A 稳妥，别拉满 2A）**：9V/12V 适配器或 PD 诱骗 9V → **buck** 模块 → pogo 送 8.4V。
- **省事（慢，用现成 5V）**：5V → **boost** 模块 → pogo 送 8.4V；或 5V → 直充电池侧面 Type-C（V2）。

> 充电电流建议设 **1A（0.5C）**，别拉满 2A——「禁止边充边用」的核心是发热，无人值守更要留温升余量。

## 5. 三个必须先验的电学/机械点

### 5.1 断载 —— V1/V2 共性的硬前提
pogo 送 8.4V 到电池 ± 时，鸭子系统仍并在这对触点上。若 robotd / 舵机没断，就是「边充边用」，违反三家厂警告。三条实现，按可靠性排序：
1. **硬件 load switch**：坞侧插入 → DETECT 信号拉低 → 板上 soft-latch 硬件断主负载（最稳，不依赖软件）。
2. **软件关机**：坞侧 DETECT → robotd GPIO 中断 → 主动 shutdown 并等待充满。⚠️ 必须实测「关机后电池仓触点与系统主回路是否真断开」——多数设计里电源键只关 DC-DC 使能，触点仍带电。
3. **二极管 ORing**：只能防倒灌，**不能**解决边充边用，别当方案。

> 复刻板（f9420 线，AP63205 降压到 5V）有没有可用的 soft-latch / 舵机电源使能脚，**是当前最大的未知**，要用万用表 + 原理图查。这一条不通，V1/V2 都只是「接着电的被动座」。

### 5.2 8.4V 顶格 + 6.6V 关断 + 电容耐压三者共存
- 2S 满电 **8.4V**，本仓既有口径里 6.6V 是唯一电学关断保护——充电回路必须与它共存，别让 8.4V 触发误关断或被误判。
- 任何并在电池上的电容耐压必须 ≥10V 且留余量。**别照搬 HAT C19 的 10V 50µF**（实物已被指偏紧，本仓靠入口并 1000–2200µF 覆盖）；**复刻板自身电容耐压要单独查**，不能张冠李戴。
- 充电时断开舵机负载后，电池只吃 1A，电压不会因大电流纹波顶到保护点。

### 5.3 电池厚度与磁头落点（与背部尺寸链合并量）
- 带口版（小布丁 / FEEL WORLD）实测 **71×39×25mm**，标准无口版约 **70.6×38.4×20.8mm**，SmallRig 4331AC 是 22.8mm 厚——差 2–4.2mm。FEEL WORLD 明写「带 Type-C 口外形会稍大，部分嵌套设备放不进去」；SmallRig 明写「无法直接插入 BMPCC 6K Pro 电池舱」。
- ⇒ **拿卡尺量我们的电池仓净厚**，再定 V1（不换电池）还是 V2（换带口版）。
- 背部 pogo 母座落点要与 `dock.py` 的 `Params`（`skid_y=22.5`、中央 |y|<22.5 带只能放按钮/灯等）一起量；和上一轮那 8 个待测量一次搞定，`base`/`tag` 两件不依赖鸭背尺寸可先打。

## 6. 与既有 SSOT 的冲突（待用户拍，未改 SSOT）

采购 SSOT 电池行写「NP-F550 **39×21×71mm** … 唯卓仕小布丁一手」，但一手资料显示**「小布丁」= 带 Type-C 直充口版 = 71×39×25mm**，而 39×21×71（20.8mm 厚）对应的是**标准无口版**。即「型号名」和「尺寸」对不上，两种可能：
- (a) 我们实际用的是**无口标准版**（那 V2 直接不成立，且「一块飞一块充」仍靠坞外座充）；
- (b) 用的是带口小布丁，但尺寸记成了无口版（那要重核电池仓能否塞进 25mm）。

**买之前先确认手上/要下单的是哪一款**。本轮不改 SSOT、不动 xlsx。

## 7. 最小可行下一步（不训练、不买板）

1. **先量**：电池仓净厚 + 电池是否带口 + 背部母座落点 + 板上有无 soft-latch / 舵机电源使能（§5.1/5.3）。零成本，纯卡尺 + 万用表 + 原理图。
2. **台架点亮充电链**（¥50 内）：`12V 适配器 → TP5100(设1A) → 假负载/旧电池 → NTC`，验 TC/CC/CV 切换、充满转灯、NTC 拔掉是否停充。这一步不碰鸭子。
3. **验断载**：确认鸭子「关机」后电池 ± 是否真与系统断开；不通就加 load switch。
4. **打印不依赖尺寸的两件**：`base` + `tag`（约 110g / 2.5h，见 `cad/microdock-upstream-stl/`）。
5. V1 的 `hood`/`board` 等所有锁鸭背尺寸的件，**等量完 §5.3 再打**。

**判决**：先做 V1 的台架电学验证 + §5.1 断载核查；V2 仅在确认「带口版塞得进仓且侧面口可够到」时才成立；V3 等视觉与策略三条前提全解再谈。
